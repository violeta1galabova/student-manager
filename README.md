# 🎓 Студентска Информационна Система

Десктоп приложение за управление на студенти, реализирано с Python и Tkinter.
Поддържа добавяне на бакалаври и магистри, въвеждане на оценки и статистика –
всичко с графичен интерфейс и запазване на данните в JSON файл.

---

## Функционалност

- **Добавяне на бакалавър** – с валидация на данните (възраст, курс, задължителни полета)
- **Добавяне на магистър/докторант** – с поле за тема на дипломна работа
- **Добавяне на оценки** – по предмет, в скала 2–6, към избран студент
- **Изтриване на студент** – с потвърждение
- **Статистика** – общ брой, среден успех на випуска, най-добър студент
- **Автоматично запазване** – всяка промяна се записва веднага в `students.json`

## ООП Архитектура

```
Person (ABC – абстрактен клас)
│
├── Student               ← бакалавър
│     ├── add_grade()
│     ├── calculate_average()
│     └── to_dict() / from_dict()
│
└── GraduateStudent       ← магистър / докторант
      └── thesis_topic

StudentManager            ← управлява списъка + JSON файла
StudentManagementGUI      ← Tkinter графичен интерфейс
```

Използвани ООП принципи: **абстракция** (ABC), **наследяване** (GraduateStudent → Student → Person), **енкапсулация** (protected атрибути с `_`), **полиморфизъм** (`get_info()` и `get_role()`).

## Формат на students.json

Данните се съхраняват като JSON масив. Пример:

```json
[
  {
    "name": "Иван",
    "age": 20,
    "id_number": "12345",
    "faculty": "ФМИ",
    "year": 2,
    "grades": [
      { "subject": "Математика", "grade": 5.5 }
    ],
    "enrolled_date": "2025-09-01"
  },
  {
    "name": "Мария",
    "age": 24,
    "id_number": "99001",
    "faculty": "ФМИ",
    "year": 5,
    "grades": [],
    "enrolled_date": "2025-09-01",
    "thesis_topic": "Машинно обучение",
    "type": "graduate"
  }
]
```

Полето `"type": "graduate"` отличава магистрите от бакалаврите при зареждане.

## Валидация

| Поле       | Правило                                      |
|------------|----------------------------------------------|
| Име        | Задължително, не може да е празно            |
| ID номер   | Задължителен, уникален                       |
| Възраст    | Между 16 и 100 години                        |
| Курс       | Минимум 1; за бакалаври – максимум 4         |
| Оценка     | Между 2.0 и 6.0                              |
| Тема       | Задължителна само за магистри/докторанти     |
